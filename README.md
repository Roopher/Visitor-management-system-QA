# Visitor Management System — QA Portfolio Project

## Project Overview

This repository documents my Quality Assurance activities for a web-based Visitor Management System. The project has been anonymized to protect the confidentiality of the client, organization, and proprietary system information.

The system was designed to support the management of visitors, including visitor registration, record management, approval processes, and monitoring of visitor activities.

The purpose of this portfolio project is to demonstrate my practical experience in software quality assurance, including requirements analysis, test planning, test scenario development, test case design, functional testing, system testing, usability testing, defect reporting, and test execution.
